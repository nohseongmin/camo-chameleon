# 🦎 CAMO CHAMELEON

> 배경색을 스포이트로 찍어 카멜레온 몸에 칠하고, **술래 스캔**을 통과해 숨어라.
> 무료 · 설치 없이 브라우저에서 바로. (일본 인디 히트작 *MECCHA CHAMELEON*의 "그려서 위장" 재미를 웹 싱글로 증류.)

**플레이:** `index.html`을 브라우저로 열면 끝. 배포는 GitHub Pages.

## 어떻게 노나
1. 🎨 **스포이트**로 배경색을 찍는다 (또는 자동 추출된 팔레트 스와치 클릭).
2. 🖌️ 카멜레온 **몸에 칠해** 배경에 녹인다. 몸이 여러 색 존을 가로지르므로 **그라데이션 위장**이 핵심.
3. 👁️ 시간이 끝나거나 "숨기 완료"를 누르면 **술래가 스캔** — 위장률(%)이 나온다.
4. 🔗 같은 **시드** 링크를 친구에게 공유 → 같은 장면에서 위장률 대결.

## 술래는 어떻게 판정하나 (백엔드 0)
사람/AI가 아니라 **픽셀 색차 알고리즘**이다: 카멜레온 몸의 각 픽셀 색을, 그 자리의 배경 픽셀 색과 비교해 평균 색거리를 구하고 위장률로 환산한다(`computeCamo()`). 가장 튀는 지점을 술래가 "지목"한다. 서버·계정·네트워크 전부 불필요.

## 스택
- **바닐라 JS + Canvas 2D**, 빌드 스텝 0, 런타임 의존성 0
- 시드 RNG(mulberry32) → 같은 시드 = 같은 장면(재현·공유)
- 절차적 WebAudio 사운드(에셋 0)
- 정적 호스팅(GitHub Pages)
